# Nemoclaw Commerce (React + Vite)

Simple ecommerce demo with:

- Login page (2 users only)
- Protected routes (no access without login)
- Dashboard (cart quantity, placed, delivered)
- Product listing from open-source API
- Side cart modal with add/remove and quantity +/-
- Checkout and order placed flow
- Profile page
- Session storage based state that clears on logout
